# Soil & Soul Nourish

## 7-Day Rotating Inpatient Menu --- Pilot Version

**Profiles:** Regular \| Diabetic-friendly \| Low-salt \| Soft-food \|
High-protein

> **Important:** This is a pilot menu framework. Quantities, calorie
> targets, carbohydrate/protein targets, and restrictions must be
> finalized by Deepa garu / the treating nutritionist for each patient.

## Day 1

### Before Breakfast

-   Regular: Milk
-   Diabetic-friendly: Unsweetened milk, if prescribed
-   Low-salt: Standard milk preparation
-   Soft-food: Warm milk
-   High-protein: Milk + nutritionist-approved protein addition

### Breakfast

-   Regular: Idly + vegetable chutney
-   Diabetic-friendly: Controlled portion of idly + vegetable chutney
-   Low-salt: Idly + low-salt chutney
-   Soft-food: Soft idly + mild chutney
-   High-protein: Idly + moong-dal-based accompaniment

### Break Snack

-   Regular: Buttermilk
-   Diabetic-friendly: Unsweetened buttermilk
-   Low-salt: Low-salt buttermilk
-   Soft-food: Thin buttermilk
-   High-protein: Buttermilk + nutritionist-approved protein snack

### Lunch

-   Regular: Rice + dal + sambar + dry kura + rasam + curd
-   Diabetic-friendly: Controlled rice + dal + vegetables + rasam
-   Low-salt: Rice + dal + vegetables + no pickle/appadam
-   Soft-food: Soft rice + dal + rasam + mashed vegetable
-   High-protein: Rice + dal + vegetable + curd + extra dal

### Evening Snack

-   Regular: Green gram gugillu
-   Diabetic-friendly: Controlled-portion boiled/sprouted green gram
    gugillu
-   Low-salt: Unsalted gugillu
-   Soft-food: Soft moong gugillu
-   High-protein: Moong gugillu + curd where appropriate

### Dinner

-   Regular: Rice + pesara pappu pulusu + dry kura + rasam + curd
-   Diabetic-friendly: Controlled rice + dal + vegetables
-   Low-salt: Low-salt dal + vegetables + rice
-   Soft-food: Soft rice + thin dal + rasam
-   High-protein: Rice + extra moong dal + vegetable

# ⭐ Signature Soil & Soul Nourish Meals

1.  **Nourish Farm Bowl** --- Millet/rice + dal/protein + 3--4 seasonal
    vegetables + greens.
2.  **Nourish Recovery Khichdi** --- Rice/millet + moong dal +
    vegetables.
3.  **Nourish Green Dal Meal** --- Seasonal greens + dal + rice +
    vegetable.
4.  **Soil-to-Soul Traditional Thali** --- Rice + dal + sambar + rasam +
    vegetable curry + pachadi + curd.
5.  **Nourish Millet Meal** --- Millet + dal + seasonal vegetables +
    greens.

## 🧠 Personalization Workflow

**Patient → Patient information & dietary requirements → Nutrition
assessment → Nutritionist recommendation → Select base recipe →
Customize portion/carbohydrate/protein/salt/texture/ingredients →
Nourish Kitchen → Quality check → Packed & labelled → Patient**

### Core principle

> **ONE RECIPE → MANY PERSONALIZED MEALS**
